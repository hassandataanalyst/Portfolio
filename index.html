FAQ

Frequently Asked Questions

Clear, practical answers about how we can work together on data projects.

Are the showcased projects real client projects?

Yes — every project in my portfolio was personally designed, built, and completed by me. From data extraction and cleaning to dashboard design and analysis, each project represents hands-on work I have done end-to-end. They reflect my real workflows, tools, and problem-solving approach.

What file formats do you work with?

I work confidently with all common data formats — CSV, Excel (.xlsx, .xls), JSON, XML, SQL databases, and API responses. I regularly extract, transform, and prepare data across these formats to produce clean, analysis-ready outputs in whatever structure your project requires.

Can you extract data from any website?

I build robust web scrapers using Python (BeautifulSoup, Requests, Selenium) for publicly accessible data. I always respect website terms of service, robots.txt guidelines, and applicable laws. I do not scrape private, authenticated, or sensitive personal data — but for public data, I can deliver structured, reliable, production-ready datasets.

Do you provide the raw code or finished dashboards?

Both — depending on what you need. I deliver documented, clean Python scripts, raw data files (CSV/JSON), static PDF reports, or fully interactive Power BI and Tableau dashboard files. Everything comes with proper documentation so you or your team can use and maintain it confidently.

How is project scope and delivery decided?

Every project begins with a clear conversation to understand your exact objectives, data sources, and expected outcomes. I then outline the deliverables, tools, and a realistic timeline. We agree on scope upfront — no surprises — and I keep you updated at every milestone until final delivery.

What tools and technologies do you use?

My core stack includes Python (Pandas, NumPy, BeautifulSoup, Requests), SQL (MySQL, PostgreSQL, SQLite), Power BI, Tableau, and advanced Excel. I also work with Git, Jupyter Notebook, and Google Colab for version control and collaborative work. I choose the right tool based on your project's specific needs.

How long does a typical project take?

Timelines depend on complexity. A focused data cleaning task or a single web scraper can be delivered in 2–4 days. A complete interactive dashboard typically takes 5–10 days. Larger analysis projects with multiple deliverables are scoped individually. I always give an honest, realistic timeline before starting.
