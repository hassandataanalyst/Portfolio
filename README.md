## ✨ Features

- **Modern Cyberpunk Theme** — Neon cyan, blue, and purple color palette with glassmorphism
- **Fully Responsive** — Optimized for mobile, tablet, and desktop
- **Horizontal Scroll Projects** — Netflix-style featured work section
- **Interactive Service Finder** — Mini-app for visitors to find relevant services
- **Case Study Drawer** — Slide-in panel for detailed project views
- **Animated Stats Counters** — CGPA, projects, and certifications with count-up animation
- **Smooth Scroll Reveals** — IntersectionObserver-based animations
- **Loading Screen** — Branded loader with animated progress bar
- **Scroll Progress Bar** — Visual indicator of scroll position
- **Back to Top Button** — Appears after 400px scroll
- **WhatsApp Floating Button** — Direct chat access with pulse animation
- **Fully Accessible** — ARIA labels, keyboard navigation, focus states
- **SEO Optimized** — Meta tags, Open Graph, Twitter cards, sitemap
